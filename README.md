# 아크로FC 샘플 보드

아크로FC 선수 21명의 측정 자료를 보여주는 정적 대시보드입니다. 선수단 요약, 피지컬·성장·멘탈 리포트, 4사분면 선수 활용 지도, 바이오밴딩 IDP를 제공합니다. 실서비스와 자동 동기화되지 않는 샘플입니다.

## 실행과 검사

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
npm test
```

로컬 주소: http://127.0.0.1:5513
`index.html`을 직접 열거나 정적 서버로 제공할 수도 있습니다.

## Vercel 배포

`npm run build`가 브라우저용 파일 13개만 `dist/`에 복사합니다. `vercel.json`에서 프레임워크를 Other(`null`)로 지정하고 이 폴더를 배포합니다. `server.js`는 로컬 미리보기 전용입니다. 연결된 GitHub main 브랜치에 push하면 Vercel이 재배포합니다.

## 자료 구성

- 선수: 아크로FC 21명 — 2014년생 3명, 2015년생 12명, 2016년생 6명.
- 측정일: 2026-09-14, 2026-09-16.
- 원자료: 사용자 제공 선수 입력 엑셀의 4–24행. 원본 엑셀은 저장소에 포함하지 않습니다.
- 경기투입양호도: 2026-10-13에 조회한 해당 팀 대시보드 스냅샷. 선수명·생년월일·측정일을 대조해 연결했습니다.
- 로그인 정보·인증 토큰·브라우저 메모는 저장소에 포함하지 않습니다.
- 성장단계별 비교 평균은 별도 실측 집단의 집계 스냅샷입니다. 팀 명단이나 팀 평균과 구분하며, 다른 팀의 개별 선수 자료는 포함하지 않습니다.
- 예상키는 입력 PAH의 −1.5cm~+7.5cm 범위로 표시합니다.

## 선수 활용 지도

- X = 성장단계 기본점수 + 골연령 월수 / 12 × 1.5 (0~10).
- 기본점수: 준비기 2, 급성장기(Stage 1·2) 5, 완성기(Stage 3·Post-PHV) 8.
- Y = MGI × 10 × 0.4 + 실제 경기투입양호도 × 0.6.
- 기준선: X=5, Y=60. 연도별 중간값에 따라 움직이지 않습니다.
- 오른쪽 위 핵심전력, 왼쪽 위 즉시전력, 왼쪽 아래 장기육성군, 오른쪽 아래 컨디션관리군.
- 세로 표시 범위는 20~100이며 20점 미만은 하단에 표시합니다.
- 선수 점은 계산 위치에 고정하고 이름만 겹침을 줄여 배치합니다.
- 현재 전체 분류: 핵심전력 5명, 즉시전력 13명, 장기육성군 1명, 컨디션관리군 2명.
- 이 분류는 코칭 참고 정보이며 실제 출전 여부나 의학적 진단을 확정하지 않습니다.

## 저장과 갱신

지도자 메모와 IDP는 현재 브라우저의 localStorage에만 저장합니다. 다른 기기나 실제 서비스로 전송되지 않습니다.

`import_workbooks.py`는 선수 입력 엑셀에서 `data.js`를 생성합니다. `import_live_snapshot.py`는 인증 정보를 포함하지 않은 연도별 API 응답 JSON을 명단과 대조해 `live-summary.js`로 변환합니다. 두 파일을 함께 갱신한 후 `npm test`를 실행하세요. 현재 연도 선택은 2014–2016년생입니다.

샘플 화면과 데이터 변경 후에는 npm test로 동작과 데이터 일치 여부를 확인하세요.
